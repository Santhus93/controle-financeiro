# Controle Financeiro - V1

Aplicacao React + TypeScript para importar e analisar localmente o CSV do Nubank.

## Instalar

```text
npm install
npm run dev
```

## Validar build

```text
npm run build
```

## Formato CSV suportado

```csv
date,title,amount
2026-10-15,Estacionamento,"11,00"
```

Os dados sao processados no navegador. Nao adicione faturas CSV ou OFX ao repositorio.
